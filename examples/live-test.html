下面这个就是真实的点赞组件。它在跟你的服务器通信，数据存在你的 MySQL 里。

试完怎么确认真的存进去了

  1. 点一下赞，数字加 1
  2. 刷新页面 —— 数字还在，按钮显示「已赞」
  3. 换个浏览器或清一下 localStorage 再来点 —— 数字继续加 （说明换了个访客，独立计数）
  4. 想去数据库里看，在 phpMyAdmin 执行：
    SELECT * FROM article_likes ORDER BY updated_at DESC LIMIT 10;

搬到你的博客上，就三步

  1. 在文章模板的正文末尾（评论框之前）加一行：
    <div class="like-widget"></div>
  2. 在模板的 <head> 里加样式表，全站只加一次：
    <link rel="stylesheet" href="/zero-dep-likes/assets/likes/likes.css">
  3. 在 </body> 之前加脚本，同样全站只加一次：
    <script src="/zero-dep-likes/assets/likes/likes.js"
            data-api="/zero-dep-likes/api/likes.php"></script>

路径里的 /zero-dep-likes/ 要按你的实际部署改。如果以后把 api/ 和 assets/ 挪到网站根目录，这两处路径里的 /zero-dep-likes 就可以去掉了。

列表页注意：那种一页显示多篇文章摘要的页面，不能用自动派生 —— 它们同处一个 URL，会算出同一个 ID 而共用一个计数。 列表页必须给每个组件写各自的 data-article-id。 真写漏了，组件会在页面上直接告警，不会悄悄错下去。
