标签页图标要看这里

  1. 看浏览器这个标签的最左边，有没有出现橙色拇指。
  2. 如果上面四张图都正常、但标签页还是没有图标 —— 多半是浏览器把之前那次 404 缓存住了。按 Ctrl + F5 强制刷新， 或者干脆开一个新的无痕窗口访问本页再看。
  3. 确认无误后，把下面这几行复制到你其他页面的 <head> 里就行 （路径按实际部署调整）：

<link rel="icon" type="image/svg+xml" href="/zero-dep-likes/assets/likes/icon.svg">

关于接口地址

/api/likes.php 返回的是 JSON 数据，不是一个网页。 浏览器把 JSON 当纯文本显示时，标签页不会给任何图标。 所以不要用接口地址来验证图标 —— 那个页面永远不会有图标，这不是坏了。
